Churn Radar

A tracker that shows subscription businesses which subscribers are at risk of churning, before they leave.

Try the live app View code
Outcome

Built solo, from data model to UI, as a real product. It has 85 passing unit tests and runs for $0 a month.

Problem

Creators and subscription businesses often notice churn only after subscribers have already left.

My role

Solo project. I scoped it, designed it and built it in Claude Code, with the goal of getting it to real users.

Key decisions
  • Privacy first: the subscriber CSV is parsed, scored and charted in the browser and never uploaded
  • Only hashed IDs, scores and summary metrics are saved, and only when a signed-in creator saves a snapshot
  • Row-level security keeps each creator's data separate, and the app still works in local-only mode
